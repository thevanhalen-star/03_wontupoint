# 광고 켜기/끄기 — 설정 방법 (Cloudflare Pages)

관리자 페이지(`https://wontupoint.com/admin/`)에서 광고를 켜고 끄려면 **한 번만** 아래 3가지를 설정하면 됩니다.
코드(`functions/`, `admin/`, `assets/ads.js`)는 이미 들어 있고, 배포(push)한 뒤 Cloudflare 쪽 설정만 하면 동작합니다.

## 0. 동작 구조 한눈에

```
방문자 → 페이지(광고 자리만 있음) → assets/ads.js → /api/ads → (KV 설정에서 켜진 광고만) → 화면에 광고 표시
관리자 → /admin/ (Cloudflare Access 로그인) → /api/admin/ads → KV 에 저장
```

- 설정을 못 불러오거나 오류가 나면 **광고를 숨깁니다**(꺼 둔 광고가 우연히 보이지 않게).
- 저장한 설정은 방문자에게 **최대 1~2분 안에** 반영됩니다(짧은 캐시 때문).
- 모든 광고에는 코드가 자동으로 `AD 광고` 표시를 붙입니다. 켜진 광고가 하나도 없으면 페이지 상단의 "광고 안내" 문구도 같이 숨겨집니다.

## 1. KV 저장소 만들고 연결 (설정값 저장 장소)

1. Cloudflare 대시보드 → **Workers & Pages → KV** → **Create a namespace** → 이름 `wontu-ads`
2. **Workers & Pages → (사이트 Pages 프로젝트) → Settings → Functions → KV namespace bindings → Add binding**
   - Variable name: `ADS_KV`  (이름이 정확히 같아야 합니다)
   - KV namespace: 방금 만든 `wontu-ads`
   - Production(필요하면 Preview 도) 에 추가

## 2. 관리자만 들어오게 잠그기 (Cloudflare Access, 무료)

1. 대시보드 → **Zero Trust → Access → Applications → Add an application → Self-hosted**
2. Application domain 을 **2개 경로**로 등록
   - `wontupoint.com` / path `admin`
   - `wontupoint.com` / path `api/admin`
3. Policy: **Allow** → Include → *Emails* → 본인 이메일(예: `thevanhalen@gmail.com`)
   - 로그인 방식은 **One-time PIN**(메일로 받은 숫자 입력)이 가장 간단합니다.
4. 저장한 뒤 애플리케이션 상세에서 **Audience (AUD) tag** 값을 복사해 둡니다.
5. Zero Trust 의 **Team domain** 도 확인합니다. (예: `myteam.cloudflareaccess.com`)

## 3. 환경 변수 2개 넣기 (서버가 로그인 토큰을 한 번 더 검증)

Pages 프로젝트 → **Settings → Environment variables → Production**

| 이름 | 값 |
|---|---|
| `ACCESS_TEAM_DOMAIN` | 예) `myteam.cloudflareaccess.com` |
| `ACCESS_AUD` | 2번에서 복사한 AUD tag |

> 이 두 값이 없으면 관리자 API 는 **무조건 막힙니다**(503). Access 정책 설정이 빠져도 열리지 않게 한 안전장치입니다.

## 4. 배포 후 확인

1. 사이트를 배포(`git push`)합니다.
2. `https://wontupoint.com/admin/` 접속 → 이메일 인증 → 광고 4개가 보이면 성공
3. 로그인하지 않은 브라우저(시크릿 창)에서 `https://wontupoint.com/api/admin/ads` → 로그인 화면이나 401/403 이 나와야 정상
4. 관리자 화면에서 광고 하나를 끄고 **저장** → 1~2분 뒤 포인트 페이지에서 그 광고가 사라지는지 확인

## 5. 사용법

- **전체 광고 노출**: 맨 위 큰 스위치. 끄면 모든 광고가 숨겨지고, 켜면 개별 설정대로 돌아옵니다.
- **광고 자리(위치)**: 자리별 스위치(예: "글 맨 끝" 광고만 끄기).
- **광고**: 광고별 스위치 · 이름 · 링크(https만) · 자리 · 가중치 · 노출 기간(시작일/종료일) · 이미지 목록.
  - 같은 자리에 켜진 광고가 여러 개면 가중치대로 번갈아 보입니다. 이미지가 여러 장이면 매번 랜덤입니다.
  - 상태 배지: `노출 중` / `꺼짐` / `자리 꺼짐` / `기간 전` / `기간 종료` / `전체 꺼짐`
- **이미지마다 링크가 다른 경우(예: 이미지 100장 + 링크 100개)**: 광고 하나의 이미지 칸에 한 줄에 한 쌍씩 `이미지주소 | 링크` 로 붙여 넣습니다. 엑셀에서 두 칸을 복사해 붙여도 됩니다(탭으로 구분). 방문자마다 이미지와 링크가 짝지어 번갈아 나옵니다.
  - 링크를 생략한 줄은 광고의 **기본 링크**를 씁니다. 이미지는 광고 하나당 300장까지입니다.
  - 이 경우 켜고 끄기는 광고 단위(묶음 전체)로만 됩니다. 개별로 켜고 끄려면 광고를 따로 만드세요.
- **새 광고 추가**: `+ 광고 추가` → 이름·링크·이미지 입력 → 스위치 켜기 → **저장**
  - 이미지는 사이트 폴더(`ad_image/…`)에 파일을 넣고 배포한 뒤, 경로(`/ad_image/005/001.jpg`)를 적으면 됩니다. 다른 사이트의 `https://…` 이미지 주소도 가능합니다.
- **새 광고 자리 추가**: 페이지에 `<div class="point-media ad-photo ad-slot" data-ad-slot="자리ID"></div>` 를 넣고, 관리자 화면 "광고 자리"에서 같은 ID 를 추가합니다.
  (포인트 상세 4곳은 이미 있고, 새 포인트를 `ingest.py` 로 변환하면 자동으로 들어갑니다. 메인 페이지 등 다른 곳은 자리를 넣을 때 알려주세요.)
- **변경 기록**: 화면 맨 아래에 최근 30건(누가·언제·무엇을 켜고 껐는지).
- 다른 창에서 먼저 저장했다면 "다른 곳에서 먼저 저장된 변경이 있습니다" 로 막아서 덮어쓰기를 방지합니다.

## 6. 문제가 생기면

- **전부 되돌리기**: KV `wontu-ads` 의 `ads_config` 키를 삭제하면 저장소의 `ads-default.json`(기본 광고 4개)로 돌아갑니다.
- **광고가 안 보임**: ① 전체 스위치 ② 자리 스위치 ③ 광고 스위치·기간 ④ 이미지 주소(관리자 화면 썸네일이 깨지면 경로 오류)를 차례로 확인하세요.
- **관리자 화면에 "KV 연결 안 됨" 경고**: 1번의 바인딩 이름 `ADS_KV` 를 확인하세요.
- **"관리자 인증 설정이 없어 접근을 막았습니다"**: 3번 환경 변수를 확인하세요(값 수정 후 재배포 필요).

## 7. 내 PC 에서 미리 해 보기 (배포 전 연습)

```bash
node tools/dev_server.mjs        # http://localhost:8788  ·  관리자: http://localhost:8788/admin/
node tools/test_ads.mjs          # 자동 점검 38개
```

개발 서버에서는 로그인(Access)을 건너뛰고, 저장한 설정은 `tools/.dev_kv.json` 에만 남습니다(실제 사이트에는 영향 없음).

## 참고: 파일 구성

| 파일 | 역할 |
|---|---|
| `ads-default.json` | 처음 상태(저장 전)의 광고 설정 — 현재 광고 4개 |
| `assets/ads.js` | 페이지의 광고 자리를 채우는 스크립트 |
| `functions/api/ads.js` | 방문자용 API (켜진 광고만) |
| `functions/api/admin/*` | 관리자 API (Access 로그인 + 출처 검사) |
| `functions/_lib/*` | 설정 검증, 로그인 토큰 검증 |
| `admin/index.html` | 관리자 화면 |
| `tools/build_site.py`, `tools/ingest.py` | 페이지에 "광고 자리"를 넣도록 수정됨 |
