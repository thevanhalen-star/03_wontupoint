페이지 변환 :

사이트 디자인(제목, 구분선, "포인트 안내" 블록, 본론 소제목),
광고 4개, 사진 배치, 카카오맵 QR, 안전 안내, 해시태그, 검색용 정보, 좌측 카테고리와 상하단 버튼까지 붙습니다.
변환 규칙은 기존 C001 페이지와 맞췄습니다.

목록 갱신 : points.json에 항목이 추가되고(주소 끝 지번은 기존 방식대로 뺌),
sitemap.xml과 rss.xml이 갱신됩니다.

중복 방지 : 이미 변환된 페이지는 다시 건드리지 않고, 원본은 tools/originals/에 보관합니다.
tools/build_site.py: 광고·좌측 카테고리 스크립트가 함께 붙도록 고쳤습니다.
이 스크립트를 다시 돌려도 지금 사이트가 깨지지 않는 것은 복사본에서 확인했습니다.

시험 결과 : 보내주신 볼락 원본에 임시 포인트명·주소를 붙인 복사본에서 변환했습니다.
본론 7개와 사진, 광고 4개 위치가 기존 포인트 페이지와 같은 구조로 나왔고,
브라우저에서 사이드바·제목·광고도 정상으로 보였습니다.

제가 임의로 정한 부분(틀렸으면 알려주세요)

이 볼락 글의 002.txt에는 포인트명과 주소 줄이 없어서,
그대로 올리면 오류 메시지를 내고 건너뜁니다.
포인트 글은 2·3줄에 포인트명과 주소가 꼭 있어야 합니다.

페이지 제목은 002.txt 1줄을 쓰고, 원본의 첫 <h1>은 쓰지 않습니다.
기존 포인트 페이지가 그렇게 되어 있어서 따랐습니다.

원본의 <h2> 본론 제목은 <h3>로, 결론 <h1>은 <h2>로 바꿉니다.

“[핵심 요약]”과 체크리스트 블록은 지우지 않고 유지합니다.
요약은 도입부 뒤에, 체크리스트는 결론 뒤에 둡니다.

사진 배치는 기존 규칙을 따릅니다.
1번은 상단, 2번은 도입부 뒤, 3번부터는 본론 뒤에 하나씩 들어가고,
광고 2·3번은 본론 2·5 뒤에, 4번은 맨 끝에 들어갑니다.

변환이 끝나면 git commit과 배포는 직접 하셔야 합니다.
