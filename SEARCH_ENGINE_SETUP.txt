ZIP 내용은 기존 points 폴더를 포함하지 않습니다. 현재 PC에 있는 points 폴더는 그대로 유지하세요.
기존 index.html을 새 index.html로 교체하고 다른 패키지 파일들을 루트에 복사하세요.
도메인이 https://wontupoint.com이 아니거나 www 주소를 대표 URL로 사용할 경우, sitemap.xml, robots.txt, rss.xml, index.html,
all-points.html, about.html, privacy.html, contact.html의 도메인을 일괄 변경해야 합니다.

구글 Search Console https://search.google.com/search-console
  1. 도메인 속성 또는 URL 접두어 속성으로 실제 대표 도메인 등록
  2. Cloudflare DNS에서 Google이 제공하는 TXT 값 등록(도메인 속성) 또는
     Google이 발급하는 HTML 파일/메타 태그로 소유권 확인
  3. 사이트맵에 sitemap.xml 제출

네이버 서치어드바이저 https://searchadvisor.naver.com/
  1. 웹마스터 도구 > 사이트 등록 > URL 입력
  2. 네이버가 발급한 HTML 파일을 루트에 올리거나, 메타 태그를 index.html head에 입력
  3. 소유확인 후 요청 > 사이트맵 제출: sitemap.xml
  4. RSS는 선택: rss.xml. 이 RSS는 상세 HTML의 본문 전체가 아닌 요약 정보만 포함합니다.
     네이버는 가능한 한 본문 전체 포함을 권장하며, 이 사이트에서는 sitemap 제출이 우선입니다.

Bing Webmaster Tools https://www.bing.com/webmasters
  1. Google Search Console 가져오기로 등록 및 소유확인 가능
  2. 또는 수동 사이트 추가 후 소유확인
  3. sitemap.xml 제출

확인해야 할 실제 주소:
  https://wontupoint.com/
  https://wontupoint.com/sitemap.xml
  https://wontupoint.com/robots.txt
  https://wontupoint.com/all-points.html
  https://wontupoint.com/points/C001/001.html

실제 검색엔진 인증용 값은 각 엔진에서 발급받아야 합니다. 이 패키지에 가짜 인증값은 넣지 않았습니다.
Cloudflare Pages에서 빌드 루트를 설정했다면 이 파일들이 배포 결과의 사이트 루트에 위치해야 합니다.
URL 목록은 검색엔진에 수집 후보를 알려주는 것으로 색인 또는 검색 노출을 보장하지 않습니다.
배포 전에 contact.html의 연락처, privacy.html의 실제 서비스 정보, 기존 포인트 본문의 정확성을 검토하세요.
